# Bird Photographer — public pages

The privacy and support pages for the Bird Photographer iOS app. App Store
Connect and TestFlight both require URLs that resolve for anyone, so these live
here, in the open, rather than in the private code repositories.

Nothing here is generated by hand. The source of truth is
`project/distribution/*.md`; `project/scripts/build_pages.py` renders it into
this directory. Edit the markdown, re-run the script, commit what changes.

Nothing under eBird's terms is in this repository — no records, no derived
tables, no code.

| Page | URL |
|---|---|
| `index.html` | the Pages root |
| `privacy.html` | App Store Connect → App Privacy → Privacy Policy URL |
| `support.html` | App Store Connect → Support URL |
